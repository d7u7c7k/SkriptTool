# Skript Tool

Minecraft Skript 개발자를 위한 VS Code 스타일 데스크톱 개발 도구입니다.

## 현재 포함된 기능

- Electron 기반 데스크톱 앱
- React + TypeScript UI
- Monaco Editor 기반 Skript 편집기
- `.sk` 파일 열기/저장
- Skript 기본 문법 하이라이트
- Explorer, Editor Tabs, Terminal Panel, Status Bar 형태의 작업 화면

## 실행

```bash
npm install
npm run dev
```

## 빌드 확인

```bash
npm run build
```

- Skript 구문 검사 및 Problems 패널 연동
